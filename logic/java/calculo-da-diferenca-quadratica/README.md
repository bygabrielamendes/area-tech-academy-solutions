## Enunciado

Dado dois números inteiros, calcule a diferença dos seus quadrados. Por exemplo, se a entrada for 3 e 5, a saída será 16, pois 5² - 3² = 25 - 9 = 16.

Exemplo de Entrada:
3
5

Exemplo de Saída:
16
