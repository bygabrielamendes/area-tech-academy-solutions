## Enunciado

Dado dois números inteiros a e b, seu objetivo é classificar a relação entre eles. Você deve imprimir "a é maior que b", "a é menor que b" ou "a é igual a b" de acordo com a comparação.

Exemplo:
Entrada:
5
3
Saída:
a é maior que b
