## Enunciado

Você deve ler dois números inteiros e calcular a soma e a diferença entre eles. Em seguida, exiba a soma e a diferença no formato: 'Soma: X, Diferença: Y', onde X é a soma e Y é a diferença. Por exemplo, se a entrada for 5 e 3, a saída deve ser 'Soma: 8, Diferença: 2'.

Exemplo:
Entrada:
5
3
Saída:
Soma: 8, Diferença: 2
