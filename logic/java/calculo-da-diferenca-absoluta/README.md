## Enunciado

Leia dois números inteiros e calcule a diferença absoluta entre eles. A diferença absoluta é o valor da subtração dos dois números, desconsiderando o sinal. Por exemplo, se os números forem 7 e 4, a diferença absoluta é 3. Se forem 4 e 7, a diferença ainda será 3. Exemplo: Para a entrada '10\n5\n', a saída deve ser '5'.
