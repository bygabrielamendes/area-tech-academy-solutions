## Enunciado

Dada a entrada de dois números inteiros, calcule a soma dos quadrados desses números. Para isso, você deve ler dois inteiros a partir da entrada padrão, cada um em sua própria linha. Depois, imprima a soma dos quadrados dessas entradas. Por exemplo:

Entrada:
3
4

Saída:
25
